# Idle AI Empire — Vision

---

# Current Milestone (2026-05-17)

**Status:** Phases 1–8 complete. PoC validated.

What's built:
- 12 upgrade tiers (GPU → Planetary Grid)
- 10 research nodes with permanent multipliers (Compute cost, linear unlock)
- Offline earnings up to 16h (with research)
- Haptics, tap particles, offline popup
- UPGRADES / RESEARCH tab UI

Next: Phase 9 (Automation) — the moment the game becomes truly idle.

---

# Core Fantasy

The player starts with a weak AI setup in a garage.

Over time they evolve into the owner of the largest compute empire in existence.

The fantasy is:
- infinite scale
- technological acceleration
- automation
- exponential growth
- becoming absurdly powerful

The player should constantly feel:
> "My empire is growing faster and faster."

---

# Pillars

## 1. Satisfying Progression

Every interaction should:
- increase numbers
- unlock systems
- create momentum
- reward optimisation

The game should avoid:
- dead time
- confusing mechanics
- excessive friction

---

## 2. Strong Theme

This is NOT a generic clicker game.

The theme should feel:
- modern
- tech-focused
- AI-inspired
- slightly satirical
- visually futuristic

Possible tone:
- corporate AI absurdity
- startup culture parody
- runaway technological growth

---

## 3. Layered Growth

Progression should evolve in layers.

### Early Game ✅
- GPUs, Server Racks, Data Centres
- manual tapping
- research unlocks early multipliers

### Mid Game ✅ (partially)
- AI Clusters, Hyperscalers, Quantum Cores
- Cooling Arrays, AI Agents, Neural Fabric
- research tree with CPS + tap multipliers

### Late Game ✅ (upgrade ladder only)
- Orbital Stations, Dyson Swarms, Planetary Grid
- top research nodes: Autonomous Replication → Planetary Consciousness

### Systems still to build
- Automation (Phase 9)
- Prestige / Singularity resets (Phase 10)
- Achievements (Phase 11)

# Monetisation Philosophy

Gameplay is validated. Monetisation can be planned, but not built until Phase 10 is complete.

Monetisation should:
- enhance progression
- never feel hostile
- respect player time

Preferred:
- rewarded ads
- optional boosts
- cosmetic purchases
- remove ads purchase

Avoid:
- aggressive interstitials
- paywalls
- energy systems
- predatory mechanics

---

# Visual Direction

Style:
- dark UI
- neon accents (cyan primary — upgrades, purple secondary — research)
- glowing stats
- futuristic dashboards
- clean monospaced typography

Inspirations:
- sci-fi control rooms
- AI server racks
- cyberpunk interfaces
- modern SaaS dashboards

---

# Success Criteria

The project succeeds if:

1. The game is satisfying to play repeatedly
2. Players return daily
3. Session length increases over time
4. Monetisation feels natural
5. The game can scale with additional content
